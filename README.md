# 📦 Smart Delivery Collection System

A secure IoT-based smart delivery system that allows users to remotely receive packages with real-time notifications, locking mechanisms, and sensor-based monitoring — even when they're not at home.

---

## 🔑 Key Features

- 🔐 **Remote Lock/Unlock** the delivery box via a Flutter mobile app
- ⚖️ **Weight Sensor** detects placed packages
- 📸 **ESP32 Camera** captures delivery snapshots
- 🧲 **Contact Sensor** checks if the box is open/closed
- 🔔 **Real-time Notifications** through MQTT and Firebase Cloud Messaging
- 📲 **Flutter App** for device setup, status, and user control
- ☁️ **Firebase Backend** for Authentication and Messaging
